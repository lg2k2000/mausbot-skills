# Worksheet Library (Source Material)

Moved from SKILL.md in v2 to keep the main file short. The worksheet names follow Liam's original page; checks marked (house) are Liam's additions, not the book's.

The eight Selling With worksheets are still authoritative for in-session work. Generate filled deal-specific versions in chat using the rules above.

1. **Deal Autopsy** — Lost deal review. Where was the decision actually made, who was in that room, what would a real champion have done.
2. **Buyer Committee Map** — Every person who'll weigh in. Buying role (User / Stakeholder / Economic / Technical / Skeptic / Champion), current priority, key metric, met yes/no. Also record each person's stance toward us (Friend / Neutral / Enemy) and the decision type they own (technical, business, financial, political). Rule: meet each person alone before any group demo.
3. **Champion Scorecard** — Four tests: change the channel, map the buying process, assign an action item, train them. Verdict: True champion / Coach / Sponsor / Friendly contact.
4. **Power Discovery Questions Workshop** — Audit your three current questions, then deploy three of the six power questions on a live call.
5. **Account Map** — Three layers (users, stakeholders, decision-makers). Profile contact priorities, metrics, info flow. Surface silent/fading contacts and cross-unit bridges.
6. **Internal Narrative Camouflage Checklist** — Audit any asset for buyer-language, internal format, champion co-authorship, forwardability.
7. **Mutual Action Plan (MAP)** — In the book a MAP is a grid of epics and tasks, each with a DRI and deadline, built back from a compelling event. The worksheet's scope / timeline / hypothesis (champion-written) / measurables (champion-written) / next steps fields are the book's five POC elements; use them when the plan includes a POC. Signal check: did the champion willingly co-author hypothesis and measurables, are at least half the owners buyer-side? Also check: does the plan run past signature to the customer's outcome? Is there an early cutoff date agreed with the buyer? Is it built back from a compelling event? (house) Is there an agreed go-dark rule (Chiarello)? (house) If the buyer won't own tasks, flag "not enough pain".
8. **90-Day Habit Commitment** — One specific behavior, frequency, deal segment, accountability partner, 30/60/90-day milestones.
