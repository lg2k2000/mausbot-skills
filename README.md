# mausbot-skills

Skills copied from the Grok Bot fleet on November 17, 2026, one folder per skill under `skills/`. Text came from the Notion mirrors of each skill and gets replaced by the Grok export after November 19, 2026.


## Per-bot folders

`bots/<bot>/` holds every skill that bot uses, copied from `skills/`, so MausBot can import a bot's whole set with one folder address (`https://github.com/lg2k2000/mausbot-skills/tree/main/bots/<bot>`). `skills/` stays the source; refresh the copies after editing a skill there.
